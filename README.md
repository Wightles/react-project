# Чат MAX

Тестовое задание на позицию frontend-разработчика: интерфейс отправки и получения текстовых сообщений MAX через GREEN-API.

## Текущий этап

Готов интерфейс чата по предоставленному макету. Приложение работает в демонстрационном режиме: сообщения добавляются только в интерфейс, запросов к GREEN-API нет.

Реализованы список и поиск чатов по номеру, создание чата с проверкой номера, переключение переписок, отдельные черновики, многострочные сообщения и форма настроек подключения. На мобильном экране список чатов и переписка открываются по очереди.

Все данные хранятся в памяти вкладки. После обновления страницы демо-чаты восстанавливаются, введённые сообщения и настройки сбрасываются. Токен не записывается в localStorage.

## Стек

- React + TypeScript.
- Vite для разработки и сборки.
- CSS без UI-библиотеки.
- Oxlint для проверки кода.

## Запуск

Используйте Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

## Проверки

```bash
npm run lint
npm run build
```

Сборка проверяет типы TypeScript и создаёт приложение в `dist`. Для локального просмотра сборки: `npm run preview`.

## Этапы реализации

1. Основа проекта – завершено.
2. Интерфейс: список чатов, переписка, форма подключения и новый чат – завершено.
3. Подключение GREEN-API и отправка текста.
4. Получение сообщений, обработка ошибок и дубликатов.
5. Проверки и итоговая инструкция.

- `src/App.tsx` – состояние чатов, черновиков и настроек.
- `src/components/ChatList.tsx` – поиск и список чатов.

- `src/components/SidebarForm.tsx` – формы подключения и создания чата.

## Проверка интерфейса

1. Найдите чат по части номера; проверьте запрос без совпадений.
2. Напишите текст: Enter добавляет сообщение, Shift + Enter переносит строку. Пустой текст отправить нельзя.
3. Оставьте черновик, переключите чат и вернитесь: черновик сохранён.
4. Создайте чат по номеру. Повторный ввод того же номера открывает существующий чат; российские номера с префиксом `8` нормализуются в `7`.
5. Откройте настройки, заполните поля тестовыми значениями и сохраните. Интерфейс сообщает, что API пока не подключён.
6. На узком экране откройте чат и вернитесь к списку кнопкой со стрелкой.

## Документация API

- [GREEN-API для MAX](https://green-api.com/max)
- [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/)
- [Получение уведомлений через HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/)

Для проверки реального обмена потребуется авторизованный инстанс MAX в GREEN-API и его `apiUrl`, `idInstance`, `apiTokenInstance`. Данные подключения будут вводиться в интерфейсе; токен не следует добавлять в исходники или коммиты.

Входящие уведомления обрабатываются последовательно: `ReceiveNotification`, обработка события, затем `DeleteNotification`. В настройках инстанса должны быть включены входящие уведомления, а `webhookUrl` должен быть пустым.
