# Чат Telegram

Тестовое задание на React: отправка и получение текстовых сообщений через [GREEN-API для Telegram](https://green-api.com/telegram). Интерфейс сделан по макету чата MAX.

Стек: React, TypeScript, Vite, CSS. Запросы к API выполняются через fetch, отдельного сервера нет.

## Запуск

Нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте адрес из терминала.

## Подключение

1. Создайте Telegram-инстанс в [кабинете GREEN-API](https://console.green-api.com/) и авторизуйте его через QR-код.
2. В настройках инстанса оставьте `webhookUrl` пустым и включите `incomingWebhook`.
3. Для уведомлений о доставке и исходящих сообщениях включите `outgoingWebhook`, `outgoingAPIMessageWebhook` и `outgoingMessageWebhook`. Для уведомлений об авторизации включите `stateWebhook`.
4. Сохраните настройки. В приложении введите `apiUrl`, `idInstance` и `apiTokenInstance` из карточки инстанса, затем нажмите «Подключиться».
5. Создайте чат по номеру с кодом страны или `@username`. Если поиск по номеру не сработал, попробуйте username.

Enter отправляет сообщение, Shift + Enter добавляет новую строку. Входящие сообщения появляются автоматически. Для проверки отправьте текст другому аккаунту Telegram и ответьте с него.

## Как работает

Отправка выполняется методом `SendMessage`. Входящие уведомления приложение получает через `ReceiveNotification` и после обработки подтверждает через `DeleteNotification`. Повторные уведомления не дублируют сообщения, при временных ошибках получение возобновляется автоматически.

Есть поиск по созданным чатам, черновики и адаптация для мобильного экрана.

## Ограничения

- Поддерживается только текст в личных чатах, до 4096 символов. Файлы и группы не отображаются.
- История, черновики и данные подключения хранятся в памяти вкладки. Обновление страницы или отключение их очищает. Токен не сохраняется в браузерное хранилище.
- Старая история из Telegram не загружается. Используйте одну вкладку приложения на инстанс, чтобы клиенты не забирали уведомления друг у друга.
- Статус «В очереди» означает, что API принял сообщение. Доставка и прочтение обновляются по отдельным уведомлениям.
- Кнопка «Отключиться» очищает данные приложения, но не завершает сессию Telegram у GREEN-API.

## Проверки и сборка

```bash
npm test
npm run lint
npm run build
```

Сборка сохраняется в `dist`. Посмотреть её локально можно командой `npm run preview`.

Отправка и получение проверены на реальном Telegram-инстансе. Тесты проверяют API-клиент, обработку уведомлений, дубликаты и ошибки на подставных ответах. Статусы доставки на реальном инстансе пока не проверены.
