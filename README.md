# Чат MAX

Тестовое задание на позицию frontend-разработчика: интерфейс отправки и получения текстовых сообщений MAX через GREEN-API.

## Текущий этап

Подготовлена основа проекта и стартовая страница. Интерфейс чата и интеграция с API ещё не реализованы.

## Стек

- React + TypeScript.
- Vite для разработки и сборки.
- CSS без UI-библиотеки.
- Oxlint для проверки кода.

## Запуск

Используйте Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

## Проверки

```bash
npm run lint
npm run build
```

Сборка проверяет типы TypeScript и создаёт приложение в `dist`. Для локального просмотра сборки: `npm run preview`.

## Этапы реализации

1. Основа проекта — завершено.
2. Интерфейс: список чатов, переписка, форма подключения и новый чат.
3. Подключение GREEN-API и отправка текста.
4. Получение сообщений, обработка ошибок и дубликатов.
5. Проверки и итоговая инструкция.

## Документация API

- [GREEN-API для MAX](https://green-api.com/max)
- [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/)
- [Получение уведомлений через HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/)

Для проверки реального обмена потребуется авторизованный инстанс MAX в GREEN-API и его `apiUrl`, `idInstance`, `apiTokenInstance`. Данные подключения будут вводиться в интерфейсе; токен не следует добавлять в исходники или коммиты.

Входящие уведомления обрабатываются последовательно: `ReceiveNotification`, обработка события, затем `DeleteNotification`. В настройках инстанса должны быть включены входящие уведомления, а `webhookUrl` должен быть пустым.
