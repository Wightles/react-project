# Чат Telegram

Тестовое задание на позицию frontend-разработчика: интерфейс отправки и получения текстовых сообщений Telegram через GREEN-API. Внешний вид сохранён по предоставленному макету чата MAX.

## Текущий этап

Готовы интерфейс, проверка подключения к GREEN-API, поиск получателя в Telegram и отправка текстовых сообщений. Получение входящих сообщений будет добавлено на следующем этапе.

Реализованы поиск по номеру или имени в созданных чатах, отдельные черновики, многострочные сообщения, состояния загрузки и ошибки. На мобильном экране список чатов и переписка открываются по очереди.

Приложение начинает работу с пустым списком чатов. Сообщения, черновики и данные подключения хранятся только в памяти вкладки и сбрасываются при обновлении страницы или отключении. Токен не записывается в localStorage или sessionStorage.

## Стек

- React + TypeScript.
- Vite для разработки и сборки.
- CSS без UI-библиотеки.
- Fetch API для запросов к GREEN-API.
- Oxlint для проверки кода.
- Встроенный тестовый раннер Node.js для тестов API-клиента.

## Запуск

Используйте Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

## Подключение и отправка

1. Создайте инстанс **Telegram** в [личном кабинете GREEN-API](https://console.green-api.com/) и авторизуйте его по [инструкции сервиса](https://green-api.com/telegram/docs/before-start/).
2. Скопируйте `apiUrl`, `idInstance`, `apiTokenInstance` из карточки этого инстанса в форму приложения. Значение `apiUrl` должно быть HTTPS-адресом сервера на поддомене `green-api.com`, без пути и параметров. Используйте параметры именно Telegram-инстанса. Токен BotFather для этого подключения не подходит.
3. Нажмите «Подключиться». Приложение вызовет `GetStateInstance` и продолжит работу только при состоянии `authorized`. Если требуется авторизация, запуск инстанса или снятие ограничений, в форме появится пояснение.
4. Введите международный номер получателя или `@username` и нажмите «Создать чат». Метод `CheckAccount` получает настоящий `chatId` Telegram. Международные номера вводятся с кодом страны; пробелы, скобки и дефисы удаляются. Российский префикс `8` преобразуется в `7`. Если номер скрыт настройками приватности, попробуйте `@username`. Поддерживаются личные чаты; группы и каналы не входят в задание.
5. Введите текст до 4096 символов и нажмите кнопку отправки или Enter. Shift + Enter добавляет новую строку.
6. После успешного `SendMessage` сообщение появится в переписке со статусом «В очереди». Это подтверждение приёма GREEN-API, а не доставки получателю. В текущей версии статус не обновляется.

При ошибке отправки текст остаётся в поле ввода. Пока запрос выполняется, повторная отправка заблокирована. При потере ответа, таймауте или ошибке сервера результат может быть неопределённым: приложение предлагает проверить Telegram перед повтором и не повторяет запрос автоматически.

Кнопка «Отключиться» находится в настройках. Она очищает данные текущей вкладки, но не разлогинивает инстанс в GREEN-API. Во время отправки отключение недоступно до завершения запроса.

Для реальной проверки нужен второй аккаунт Telegram или доступный получатель. Ответ получателя пока можно увидеть только в самом мессенджере.

## Проверки

```bash
npm test
npm run lint
npm run build
```

Тесты API-клиента подставляют ответы `fetch` и не отправляют настоящие сообщения. Они проверяют адреса и тела запросов, авторизацию, проверку получателя по международному номеру и @username, лимит текста, HTTP-ошибки, таймаут, отмену и отсутствие автоматических повторов. Для запуска тестов используется поддержка TypeScript в Node.js 24, отдельный тестовый фреймворк не требуется.

Сборка проверяет типы TypeScript и создаёт приложение в `dist`. Для локального просмотра сборки: `npm run preview`.

Интерфейс также проверен в Chrome с перехватом API-запросов: подключение, ошибки, отмена запроса при закрытии формы, создание чата, сохранение черновика, переключение чатов во время отправки и мобильная вёрстка. Реальная доставка через авторизованный инстанс пока не проверена.

## Структура исходников

- `src/App.tsx` – состояние подключения, чатов, черновиков и отправки.
- `src/api/greenApi.ts` – запросы, проверка ответов, таймаут и понятные ошибки.
- `src/components/ChatList.tsx` – поиск и список чатов.
- `src/components/ChatWindow.tsx` – переписка, ошибки отправки и поле сообщения.
- `src/components/SidebarForm.tsx` – подключение и создание чата.
- `src/components/Icon.tsx` – иконки и аватар.
- `src/types.ts`, `src/utils/format.ts`, `src/constants.ts` – типы, форматирование и лимит сообщения.
- `tests/greenApi.test.mjs` – тесты API-клиента.

## Этапы реализации

1. Основа проекта – завершено.
2. Интерфейс чата – завершено.
3. Подключение GREEN-API и отправка текста – реализовано, требуется проверка на реальном инстансе.
4. Получение сообщений, обработка уведомлений и дубликатов.
5. Итоговые проверки и инструкция для сдачи.
